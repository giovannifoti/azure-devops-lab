## Workflow completato

Ho preparato la cartella di lavoro ~/workspace e verificato il corretto funzionamento di macOS, Visual Studio Code, Git, GitHub CLI e Azure CLI. Ho clonato separatamente il repository pubblico del corso e il repository personale azure-devops-lab, mantenendo il materiale del docente distinto dalle mie consegne. Ho configurato Git e verificato l'autenticazione GitHub tramite HTTPS. Ho quindi creato nel repository personale la struttura prevista per l'UD01 e copiato il template dell'evidenza. git status viene utilizzato per controllare i file nuovi o modificati; git add servirà a inserire nello staging soltanto i file previsti per la consegna; git commit registrerà la versione locale dell'attività e git push la pubblicherà sul repository remoto GitHub. Infine ho installato Azure CLI, attivato una sottoscrizione Azure e verificato che la sottoscrizione predefinita risulti abilitata.
