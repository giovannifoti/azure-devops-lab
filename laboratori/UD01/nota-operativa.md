# Nota operativa — UD01

La cartella di lavoro si trova nel filesystem locale di macOS ed è stata aperta con Visual Studio Code tramite il comando code ..

Il controllo utilizzato per verificare il corretto contesto di esecuzione è:

pwd

L'output indicava una directory workspace interna alla home dell'utente macOS.

L'architettura della macchina è stata verificata tramite:

uname -m

Il comando ha restituito arm64.

La versione del sistema operativo è stata verificata tramite:

sw_vers

La postazione utilizza macOS 26.6.2, build 25G83.
